# API to CSV Project

Este proyecto hace una petición GET a la API de JSONPlaceholder (https://jsonplaceholder.typicode.com/users),
obtiene los datos de usuarios, los transforma en un DataFrame de pandas y los guarda en un archivo CSV.

## Requisitos

- Python 3.x
- requests
- pandas

## Uso

1. Clona el repositorio
2. Crea y activa un entorno virtual
3. `pip install -r requirements.txt` (una vez que lo generes)
4. Ejecuta `python api_to_csv.py`
